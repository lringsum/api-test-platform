# 第九阶段：边界值测试设计

## 1. 说明

本文件用于沉淀平台各模块的边界值测试场景，覆盖以下异常与边界类型：

- 空值
- 非法格式
- 重复数据
- 接口异常
- JSON 错误
- AI 返回异常
- 断言失败

本测试设计可用于：

- 手工测试清单
- 回归测试 checklist
- 后续 pytest 自动化测试用例设计基础

## 2. 项目管理模块

| 测试场景 | 输入 | 预期结果 |
| --- | --- | --- |
| 项目名称为空 | `name=""` | 页面提示“项目名称不能为空”，不保存 |
| 项目名称仅空格 | `name="   "` | 视为空值，提示不能为空 |
| 项目描述为空 | `description=""` | 允许保存，描述为空字符串 |
| 项目名称重复 | 已存在 `用户中心测试`，再次创建同名项目 | 提示“项目名称已存在”，不保存 |
| 编辑不存在项目 | `project_id=999` | 提示“项目不存在” |
| 删除不存在项目 | 删除一个已被删除的项目 ID | 提示“项目不存在” |
| 项目状态非法 | 提交 `status=unknown` | 当前可保存，建议后续收紧校验 |
| 数据库为空访问项目页 | 无任何项目 | 页面正常打开，表格为空 |
| 删除有级联数据的项目 | 项目下有模块、环境、变量、用例、执行记录 | 项目删除成功，关联数据级联删除 |
| 超长项目名 | 长度超过数据库限制 | 数据库或服务层报错，页面给出失败提示 |

## 4. 环境管理模块

| 测试场景 | 输入 | 预期结果 |
| --- | --- | --- |
| 环境名称为空 | `name=""` | 提示“环境名称不能为空” |
| `base_url` 为空 | `base_url=""` | 提示“Base URL 不能为空” |
| `base_url` 只有空格 | `base_url="   "` | 视为空值，提示不能为空 |
| 请求头 JSON 为空对象 | `headers_json={}` | 允许保存 |
| 变量 JSON 为空对象 | `variables_json={}` | 允许保存 |
| 请求头 JSON 非法 | `headers_json="{bad"` | 提示 JSON 格式错误 |
| 变量 JSON 非法 | `variables_json="{bad"` | 提示 JSON 格式错误 |
| 请求头 JSON 是数组 | `headers_json=[]` | 提示“环境请求头 JSON 必须是对象” |
| 变量 JSON 是数组 | `variables_json=[]` | 提示“环境变量 JSON 必须是对象” |
| 同项目环境重名 | 项目下已存在 `测试环境` | 提示“同一项目下环境名称已存在” |
| 不同项目环境同名 | 两个项目都有 `测试环境` | 允许保存 |

| 超长 URL | 很长的 `base_url` | 能保存则正常，执行时按完整 URL 处理 |
| 非 HTTP URL | `base_url=ftp://abc` | 当前未限制协议，执行时可能请求异常 |

## 5. 变量管理模块

| 测试场景 | 输入 | 预期结果 |
| --- | --- | --- |
| 变量名称为空 | `name=""` | 提示“变量名称不能为空” |
| 变量值为空字符串 | `value=""` | 允许保存 |
| 变量作用域非法 | `scope="global"` | 提示作用域非法 |
| 环境级变量缺环境 ID | `scope=environment` 且 `environment_id=None` | 提示必须指定环境 |
| 环境级变量环境不存在 | `environment_id=999` | 提示环境不存在或与项目不匹配 |
| 环境级变量项目不匹配 | 环境不属于当前项目 | 提示环境与项目不匹配 |
| 同作用域变量重名 | 同项目同环境下重复 `token` | 提示“当前作用域下变量名称已存在” |
| 项目级与环境级同名变量 | 项目级 `token`，环境级也有 `token` | 允许保存，运行时环境级覆盖项目级 |
| 变量名含特殊字符 | `name="token-value"` | 当前数据库允许，建议后续收紧命名规范 |
| 变量引用不存在 | 用例中 `${token}`，未配置变量 | 执行失败并记录“变量未定义” |
| 环境 JSON 与变量表同名 | 环境中 `token=abc`，变量表 `token=xyz` | 运行时变量表覆盖环境 JSON |
| 删除变量后执行依赖用例 | 删除 `token` 后执行依赖该变量的接口 | 执行失败并记录变量未定义 |

## 7. 已下线能力

AI 解析、AI 生成、AI 修复和 Prompt 模板已从当前业务代码下线。相关页面与 API 路由应返回 404；普通用例、Web 自动化脚本、版本和运行记录不得受影响。

## 8. 接口执行引擎

| 测试场景 | 输入 | 预期结果 |
| --- | --- | --- |
| 执行单用例时未选环境 | `environment_id=None` | 执行失败，提示环境不存在或不匹配 |
| 环境不存在 | `environment_id=999` | 执行失败 |
| 环境停用 | `is_active=False` | 执行失败 |
| 环境 `base_url` 为空 | `base_url=""` | 执行失败 |
| 用例不存在 | `testcase_id=999` | 执行失败 |
| 用例停用 | `is_active=False` | 执行失败 |
| 模块执行时无启用用例 | 模块全部停用 | 返回“没有可执行的启用用例” |
| 项目执行时无启用用例 | 项目全部停用 | 返回“没有可执行的启用用例” |
| 变量未定义 | body 或 header 中 `${token}` 未配置 | 该用例失败并记录错误 |
| URL 中变量未定义 | `/api/users/${id}` 无变量 | 该用例失败 |
| Header 中变量替换 | `Authorization: Bearer ${token}` | 正常替换后发请求 |
| Body 中变量替换 | `{"user_id":"${user_id}"}` | 正常替换 |
| Params 中变量替换 | `params={"id":"${user_id}"}` | 正常替换 |
| 前置提取变量透传 | 第一条提取 `token`，第二条使用 `${token}` | 模块/项目批量执行时后续可用 |
| 请求超时 | 接口超过超时时间 | 记录请求异常，状态失败 |
| 接口连接失败 | URL 不可达 | 记录请求异常 |
| 接口返回 500 | 服务端异常 | 记录响应并断言失败 |
| 响应过长 | 超长文本响应 | 文本截断保存，不导致数据库膨胀 |
| 响应非 JSON | HTML 页面 | `json_path` 断言失败，提取失败 |
| GET 请求执行 | `method=GET` | 使用 `params` 发送 |
| POST 请求执行 | `method=POST` | 使用 `json body` 发送 |

## 10. 断言系统

| 测试场景 | 输入 | 预期结果 |
| --- | --- | --- |
| `status_code` 成功 | 期望 `200`，实际 `200` | 断言通过 |
| `status_code` 失败 | 期望 `200`，实际 `500` | 断言失败，记录实际值 |
| `json_path` 成功 | `path=code`，实际 `0` | 断言通过 |
| `json_path` 路径不存在 | `path=data.token`，无该字段 | 断言失败 |
| `json_path` 响应非 JSON | 返回 HTML | 断言失败并提示无法执行 json_path |
| `contains` 成功 | 响应中包含 `success` | 断言通过 |
| `contains` 失败 | 响应不含关键字 | 断言失败 |
| `response_time` 成功 | 阈值 `3000`，实际 `800` | 断言通过 |
| `response_time` 失败 | 阈值 `1000`，实际 `2500` | 断言失败 |
| `response_time` 阈值非法 | `expected="abc"` | 断言失败 |
| 多断言部分失败 | 4 条断言 2 条失败 | 用例整体失败，断言明细完整保存 |
| 空断言数组 | `assertions=[]` | 保存阶段已拦截，不进入执行阶段 |

## 11. 变量提取模块

| 测试场景 | 输入 | 预期结果 |
| --- | --- | --- |
| 提取成功 | `extract={"token":"data.token"}`，响应有该字段 | 成功提取并写入运行时变量 |
| 提取路径不存在 | `data.token` 不存在 | 记录 `success=false`，不抛系统异常 |
| 响应非 JSON | HTML 响应 | 提取失败，提示响应不是 JSON |
| `extract` 为空对象 | `{}` | 正常执行，不报错 |
| `extract` 非对象 | `extract=[]` | 保存阶段已拦截 |
| 提取值为数字 | `user_id=1001` | 正常提取 |
| 提取值为布尔 | `success=true` | 正常提取 |
| 提取数组下标 | `data.0.token` | 如果结构匹配则可取到值 |
| 后续用例覆盖同名变量 | 再次提取 `token` | 运行时变量更新为最新值 |
| 提取失败后后续用例依赖该变量 | 第二条依赖 `${token}` | 未成功提取则后续执行失败 |

## 12. 执行结果模块

| 测试场景 | 输入 | 预期结果 |
| --- | --- | --- |
| 执行成功 | 所有断言通过 | `Execution.status=passed` |
| 执行失败 | 有任意断言失败 | `Execution.status=failed` |
| 批量执行部分失败 | 10 条中 2 条失败 | 总数、通过数、失败数、通过率计算正确 |
| 单用例执行明细保存 | 1 条用例执行完成 | 生成 1 条 `ExecutionDetail` |
| 批量执行明细保存 | 执行 5 条用例 | 生成 5 条 `ExecutionDetail` |
| 请求异常时保存明细 | 超时或连接失败 | 明细仍落库，带错误信息 |
| 响应为空 JSON | 无法解析 JSON | `response_snapshot.json=None` |
| 执行耗时为 0 | 极快接口 | 正常保存 |
| 历史执行按时间查看 | 多条执行记录 | 页面按创建时间倒序展示 |
| 删除原始用例后查看历史 | 用例已删除 | 仍可通过 `testcase_name` 查看历史明细 |

## 16. 结论

本文件已经覆盖平台当前版本的大部分高风险边界场景。后续如新增以下能力，建议同步扩充测试表：

- 用户登录和权限控制
- MySQL 切换
- 异步任务执行
- 定时调度
- 更多请求方法和断言类型
